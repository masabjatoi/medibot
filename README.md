# medibot
AI healthcare assistant 


🩺 MediBot – AI-Powered Healthcare Assistant
MediBot is an AI-based chatbot designed to answer healthcare-related queries by extracting information directly from a PDF dataset. Powered by the Mistral language model, Sentence Transformers, and a clean Streamlit GUI, it provides accurate, real-time answers from medical documents.

🔍 Features
📄 PDF-Based Knowledge: Upload any medical document as the knowledge base.

🤖 Smart Q&A: Asks and answers natural language questions using Mistral and embeddings.

💬 Semantic Search: Uses Sentence Transformers for context-aware query understanding.

🖥️ Interactive Interface: Built with Streamlit for a user-friendly experience.

🐍 Python-Powered: Simple and extensible backend using Python.

🛠️ Technologies Used
Python

Mistral LLM

Sentence Transformers

Streamlit

PyMuPDF / pdfplumber (for PDF parsing)

📌 Use Cases
Patient education tools

Medical knowledge retrieval

Personal health assistance

Training medical staff on internal documentation
